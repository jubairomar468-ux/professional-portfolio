# Jubair Hamza — Interactive Portfolio (GitHub Pages)

Same content and design as `Jubair_Portfolio.html`. The embedded PDFs and page
images were moved into separate files so every file is under GitHub's 25 MB
browser-upload limit.

| Path | Content |
| --- | --- |
| `index.html` | The whole portfolio (layout, text, navigation) |
| `docs/` | 23 original PDFs ("Open original PDF") |
| `pages-1/`, `pages-2/` | Page images shown in the in-site document viewer |
| `.nojekyll` | Tells GitHub to serve files as they are |

## Upload (GitHub accepts max 100 files per upload, so use two uploads)

1. Upload 1: `index.html`, `README.md`, `.nojekyll`, `docs`, `pages-1` → Commit.
2. Upload 2: `pages-2` → Commit.
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
